# HARON TV

تطبيق Android لبث القنوات التلفزيونية عبر الإنترنت باستخدام قائمة M3U.

## المزايا
- شعار HARON TV وشاشة بداية احترافية.
- تشغيل القنوات عبر Media3/ExoPlayer.
- البحث عن القنوات.
- تصنيف القنوات حسب الأقسام.
- إضافة وإزالة القنوات من المفضلة بالضغط المطوّل.
- زر تحديث قائمة القنوات.
- وضع ملء الشاشة للفيديو.
- واجهة داكنة مناسبة للهواتف.
- بناء APK تلقائيًا بواسطة GitHub Actions.

## مصدر القنوات
القائمة الحالية:
`https://m3umaker.com/view/1550/haron1971`

## بناء APK من الهاتف
1. ارفع المشروع إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. اختر **Build Haron TV APK**.
4. اضغط **Run workflow**.
5. بعد نجاح البناء افتح نتيجة التشغيل ونزّل `HaronTV-debug-apk`.
